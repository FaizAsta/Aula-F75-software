Keyboard

Connection

Keyboard model

Sets the preview layout and which key each light belongs to. The F75, F75 Pro and F87 can report the same USB id, so the app cannot always tell them apart: pick yours if the preview looks wrong.

Keyboard tools

Restore settings after a reset

Off by default. When on, your settings are written back if the keyboard comes back with different ones, for example after sleep or a restart. When off, connecting changes nothing on the keyboard.

Brightness levels

How many brightness steps the Lighting tab offers. It grows by itself when the keyboard reports a higher level, for example after you raise it with the keyboard's own brightness keys. A number above what your keyboard supports may do nothing.

Demo keyboard

A simulated keyboard, so you can try every control without hardware.

Connection help

  • 2.4G dongle Battery, effects, colours and per-key lighting. The most tested option.
  • USB-C cable Tried automatically. Some units use a cable protocol this app cannot speak. If it stays silent, use the dongle.
  • Bluetooth Battery only, and only if Windows reports it. Windows does not allow lighting commands over Bluetooth.
