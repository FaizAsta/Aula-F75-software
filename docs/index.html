Light up your AULA keyboard.

A free, unofficial Windows and Linux app for AULA F75 keyboards. Pick lighting effects, paint single keys, check the battery and watch a live preview of your board.

Download See screenshots
Made for myself, shared for anyone.

I built this because AULA's official software is hard to use. It was made with the help of AI, it is free, and you use it at your own risk. It has only been tested on the AULA F75. The F75 Pro, F87, F75 Max and F75 HE are untested. Not affiliated with AULA.

What it does

Battery

See the battery level and charging state. Get alerts when it is low or fully charged, plus a history and an estimate of what is left.

Static, Breathing, Rainbow, Flash away, Raindrops, Rainbow wheel, Ripples, Twinkling stars, Snake, Neon stream, Reactive, Sine wave, Windmill, Color waterfall and Blossom. The F75 Max has 20 effects and the F75 HE has 19.

Download and install

Everything is on the Releases page.

Windows 10 and 11

  1. Download Aula-Control-Setup.exe and run it. No admin rights needed. Or take Aula-Control-Portable.exe, which needs no install.
  2. If Windows warns about an unknown publisher (the app is not code-signed), choose More info, then Run anyway.
  3. Close AULA's official driver. Only one program can use the keyboard at a time.
  4. Plug in the 2.4G dongle or USB-C cable, press Start and pick your keyboard.

Linux, 64-bit (new and untested)

  1. Ubuntu, Debian, Mint, Pop!_OS: download Aula-Control-amd64.deb, double-click it and press Install. Then unplug and plug the keyboard once.
  2. Any other distro: download Aula-Control-x86_64.AppImage, allow it to run as a program, then double-click it.
  3. The AppImage cannot set up keyboard access itself. Download 99-aula-control.rules from the same release, run this, then replug the keyboard: 
    sudo cp 99-aula-control.rules /etc/udev/rules.d/ && sudo udevadm control --reload-rules && sudo udevadm trigger

No keyboard? Press Start, open Demo keyboards and pick a demo F75, F75 Max or F75 HE. Stuck? Open Settings, Connection help and save a log, then ask on Discord. The red low-battery light only works while the app is running, so turn on Start with Windows if you want it always on.

Try it with your keyboard

It is free. If something does not work, say so on Discord and it can be fixed.
